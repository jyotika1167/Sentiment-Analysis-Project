# Sentiment Analysis Project

## Overview

This project demonstrates sentiment analysis using Natural Language Processing (NLP) techniques.

## Tools and Technologies

* Python
* Google Colab
* TextBlob
* Pandas
* Matplotlib

## Project Workflow

1. Load textual reviews
2. Analyze sentiment polarity
3. Classify sentiments as Positive, Negative, or Neutral
4. Visualize sentiment results using graphs

## Output

The model successfully identifies sentiments from text reviews and displays sentiment distribution graphically.
